# Analyse avancée des ventes de pizzas – Dashboard SQL & Power BI

**Projet inspiré de** : [Data Tutorials](https://www.youtube.com/@datatutorials1) • [Dataset source](https://drive.google.com/drive/folders/17U0ah6Q4MJM_wIn_Xl4fHc-1fO6Q4s6z)

Dashboard interactif sur ~48k lignes de ventes annuelles. Objectif : KPIs commerciaux, habitudes clients, identification best/worst sellers.

## Objectifs & KPIs
- **CA total • Valeur moyenne commande • Pizzas/commandes totales**
- **Tendances journalières/mensuelles • Répartition catégorie/taille**
- **Top/Bottom 5 pizzas (CA, quantité, commandes) • Jours/heures chargés**

## Stack technique
**MS SQL Server** (requêtes) • **Power BI Desktop** (DAX, viz) • **CSV → SQL** (pizza_sales.csv)

## Insights clés
- **Classic** domine ventes/commandes
- **Large** = max CA
- **Pic weekend** (vendredi/samedi soir) + **juillet/janvier**
