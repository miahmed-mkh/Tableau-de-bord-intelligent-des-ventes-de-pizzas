# Pizza Sales Analysis – SQL & Power BI Dashboard

## Main Steps
1. CSV import to SQL Server, modeling `pizza_sales` database
2. SQL queries for KPIs, trends, top/bottom rankings
3. Power BI connection to SQL Server
4. Data cleaning/transformation via Power Query
5. DAX measures creation (revenue, avg order value, etc.)
6. Two dashboards built:
   - **Dashboard 1**: KPIs, daily/monthly trends, category/size breakdown, busiest days/hours
   - **Dashboard 2**: Top 5 / Bottom 5 pizzas by revenue, quantity, orders

## Objectives & KPIs
- **Total Revenue • Avg Order Value • Total Pizzas/Orders**
- **Daily/Monthly Trends • Category/Size Breakdown**
- **Top/Bottom 5 Pizzas (Revenue, Quantity, Orders) • Busiest Days/Hours**

## Key Findings
- **Classic** category drives max sales & orders
- **Large** pizzas generate highest revenue
- Peak orders on weekends (Fri/Sat evenings)
- Best/worst sellers identified for marketing decisions

# Analyse des ventes de pizzas – Dashboard SQL & Power BI

## Étapes principales
1. Import du fichier CSV dans SQL Server et modélisation de la base (`pizza_sales`).
2. Écriture de requêtes SQL pour répondre aux besoins métiers (KPIs, tendances, tops/bottoms).
3. Connexion de Power BI à SQL Server.
4. Nettoyage et transformation des données via Power Query.
5. Création des mesures DAX (revenu, moyenne par commande, etc.).
6. Conception de deux dashboards :
   - **Dashboard 1** : KPIs, tendances journalières/mensuelles, répartition par catégorie et taille, jours/horaires les plus chargés.
   - **Dashboard 2** : Top 5 / Bottom 5 pizzas par revenu, quantité et nombre de commandes.

## Objectifs & KPIs
- **CA total • Valeur moyenne commande • Pizzas/commandes totales**
- **Tendances journalières/mensuelles • Répartition catégorie/taille**
- **Meilleures / Pires 5 pizzas (CA, quantité, commandes) • Jours/heures chargés**

## Résultats clés
- La catégorie **Classic** contribue au maximum des ventes et des commandes.
- Les pizzas de taille **Large** génèrent la plus grande part du chiffre d'affaires.
- Les commandes sont les plus élevées le week-end, surtout les soirs de vendredi et samedi.
- Identification des pizzas best-sellers et underperformers pour guider les décisions marketing.
